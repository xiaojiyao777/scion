## 8. P0 / P1 修复建议

### P0

1. 修复 CVRP `or_opt_1_relocation` novelty matcher。
   必须把以下模式判为 allowed variant，而不是 premise contradiction：
   `existing/current/active VNS has _or_opt_1/_or_opt_2/_or_opt_3 ... with no distance filter`、
   `with no candidate list`、`with no adaptive ordering`、`restrict existing Or-opt targets`。
   添加回归测试覆盖本 run 的 step 3、4、7 原文。

2. 调整 `allowed_variant_guidance` 与 `variant_allowed` 的一致性。
   如果 guidance 明确说 filtering / scoring / budget variant allowed，则 gate 不应继续以
   `or_opt_1_relocation` missing-premise 拦截。否则 feedback 会误导 agent 和 postrun 判断。

3. 对 low-confidence novelty contradiction 不消耗 full proposal-quality block，或至少自动发起
   semantic retry。
   本 run 有 3/6 block 是 framework/provider false positive，直接导致
   `proposal_quality_loop` 停止。可用 heuristic：当 hypothesis 同时出现 active operator 名称和
   `filter/candidate/order/adapt` 等 modifier 时，降级为 retry constraint 而非 terminal block。

4. 给 algorithm smoke failure 返回 machine-readable debug payload。
   至少包括：smoke case id / customer_count、declared mechanism trigger fields、observed
   mechanism-specific fields、缺失字段、是否因 trigger/no-op/remaining time 跳过。这样 step 1/5
   的 agent 才能精准降低 trigger 或记录 evaluation no-op activation。

### P1

1. C11 schema preview 输出完整 legal template artifact ref。
   当前 summary 中 `Legal expected_t...` 被截断。应把 legal activation/activity/budget/effect
   fields 作为结构化字段保存并暴露给 retry prompt。

   Step 6 是 activation/runtime observed 但 effect zero。建议 summary 增加
   `telemetry_effect_zero_experiments` 或 `mechanism_effect_not_observed`，避免被误解为 telemetry
   缺失。

3. 对 repeated same-mechanism false rejection 增加 campaign-level dedupe。
   连续出现 `or_opt_1_relocation` premise contradiction 时，应自动禁止同一 matcher 再 terminal
   block 相似文本，或把 feedback 注入下一轮 tool-selection 黑名单。

   在 win-rate spread=0 且 false-positive loop 中，要求 agent 优先选择非 `local_search.py`
   owner file 或不同 mechanism family，减少在 Or-opt/VNS 表述上反复触发 matcher。

5. 在 active fact packet 中显式暴露 allowed-variant examples。
   例如 `or_opt_1_relocation.active` 下给出：“candidate filtering, trigger tuning,
   ordering/scoring changes are variants, not missing Or-opt claims”。这比事后 rejection guidance

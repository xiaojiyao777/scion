## 8. 剩余 P0 / P1 修复建议

### P0 - 修 construction premise matcher 的 nearest-neighbor-only false positive

问题：
`(sweep, Clarke-Wright, capacity-balanced, nearest-neighbor) generates a single seed`
被误判为 “active baseline uses only a single nearest-neighbor seed”。这是明确 false positive。

建议：

- CVRP construction matcher 只在显式缺失/only claim 时触发 contradiction，例如
  “only nearest neighbor”, “nearest-neighbor-only”, “no sweep”, “no Clarke-Wright”。
- 对 parenthetical portfolio list 中的 `nearest-neighbor` 不触发 missing-premise。
- 增加 regression fixture，直接使用本 run 的 final hypothesis span。
- 在 adapter facts/guidance 中加入：
  “active construction is diverse but selects one incumbent trajectory; multi-start / restart / seed schedule variants are allowed if they acknowledge existing construction methods.”

### P0 - 修 Shaw/proximity-cluster hard block 的分类和 retry

问题：
`cluster_removal` 明确承认 `_shaw_removal`，但被硬判为 “related/proximity-cluster removal missing”。
即使 adapter 认为它与 Shaw family 过近，也不应归为 `premise_contradicted`。

建议：

- 将显式 contrast pattern（`unlike existing shaw_removal`、`existing _shaw_removal`）从
  hard contradiction 里排除。
- 若 cluster/zone proposal 与 Shaw family 太近，返回 semantic retry：
  `duplicate_or_under_differentiated_variant`，而不是 premise contradiction。
- guidance 应要求二选一：改为 modify existing `_shaw_removal` scoring/trigger/schedule，
  或说明 centroid fixed-zone、route-independent removal 相对 seed-ranked Shaw 的 observable
  telemetry/behavior 差异。

### P1 - telemetry effect failure detail 更细分

问题：
Step 1 的正式 metrics 已有 `activation_status=observed`、`runtime_status=observed`、
`effect_status=zero`，但 `status.json` 里 failure detail 使用 `missing_fields`，且
`mechanism_id=null`。这会让人工分析误以为是字段缺失或 telemetry wiring failure。

建议：

- decision detail 增加 `mechanism_id`。
- 将 `TELEMETRY_EFFECT_NOT_OBSERVED` 拆成至少两类：
  `TELEMETRY_EFFECT_ZERO` 与 `TELEMETRY_EFFECT_FIELD_MISSING`。
- `missing_fields` 只放真正 missing 的字段；present-but-zero 放 `zero_fields` 或
  `effect_status=zero`。

### P1 - 保留 compact C11 / smoke feedback 的关键可执行片段

问题：
多个 schema/smoke feedback 被 `[truncated by proposal tool result budget]` 截断。Agent
大多仍能修复，但人工复盘和后续 semantic retry 难以判断具体 guidance。

建议：

- 对 preview/smoke failure 摘要采用 structured short form：`code`、`field`、`mechanism_id`、
  `required_template`、`one-line repair_guidance`。
- 即使完整 observation 被截断，也保留 typed minimal failure object。

### P1 - adapter facts 增加“允许变体”正例

问题：
active facts 已能阻止明显 missing-premise，但对“承认现有机制并提出变体”的正例不足。

建议：

- construction facts：新增 “diverse construction exists, but one selected seed/trajectory per solve”。
- Shaw facts：新增 “Shaw is proximity-related; allowed variants must either modify Shaw or prove material distinction”。
- local_search facts：保持本轮有效修复，继续允许 `candidate_list` / `pruning` / `adaptive ordering`
  在承认 `_or_opt_*` 已存在时通过 novelty gate。

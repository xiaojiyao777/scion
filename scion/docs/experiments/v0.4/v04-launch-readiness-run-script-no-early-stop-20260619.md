# v0.4 Launch Readiness Run-Script No-Early-Stop Guard

Date: 2026-06-19

## Purpose

The next warehouse and CVRP follow-up campaigns are v0.4 effective-research
checks. Prepared launch roots must not stop early before the agent has a chance
to produce useful continuation evidence.

## Change

`scion/tools/check_launch_readiness.py` now exposes
`run_script_no_early_stop_enforced`.

The check requires:

- `launch.env` declares `DISABLE_EARLY_STOP=1`;
- `prepared_run_manifest.v1.json` command includes `--disable-early-stop`;
- the real generated `run.sh` campaign command block includes
  `--disable-early-stop`.

Logged `COMMAND:` lines are ignored when locating the real campaign command.
The check supports the multiline `run.sh` command shape generated by the CVRP
and warehouse launchers.

## Boundary

This is a launch/readiness guard only. It does not change Decision,
`DecisionFeatures`, Protocol gates, promotion, scheduler state, proposal
semantics, problem solvers, or experiment evidence.

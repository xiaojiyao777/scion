## Audited causal diagnosis

Read-only code inspection and a local no-network reproduction identify the
causal class as
`RUN_INVALID_LOCAL_INFRA / MISSING_JITER_BEFORE_REQUEST`. The bundled Python
environment contains OpenAI code whose lazy chat-completions resource imports
`from jiter import from_json`, but `jiter` is absent from the minimal formal
environment. Accessing `client.chat` therefore raises `ModuleNotFoundError`
before `client.chat.completions.create(...)` can emit the model request.

The production transport's broad SDK exception classifier wraps that local
import error as `LLMError("API error: ...")`; the experiment runner then maps
all caught `LLMError` values to its durable provider-failure class. The
artifacts are truthful about that emitted classification and are not rewritten,
but the audited cause is local infrastructure rather than provider behavior.

zero provider-visible research payload sends. Launcher auth/status and model-

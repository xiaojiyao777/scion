Equal-count even selectors use the existing manifest-index spacing rule with
n=8:

- synthetic: `m01,m03,m06,l02,l04,s02,ml02,ml04`;
- production: `micro01,micro03,s01,s03,ms02,m01,m04,ml02`.

The stratified selector is one candidate-independent cohort per universe, not
one favorable cohort per comparison. It takes two cases from each of four
predeclared size cells. Inside a cell it selects one low- and one high-headroom
case using only the exact v1 base's absolute per-case median
`subcategory_splits` headroom to lower bound zero. Structure diversity breaks
ties, followed by manifest order:

- synthetic structure: capacity pressure, locked presence, hazard ratio and
  subcategory count; size cells small/medium/medium-large/large;
- production structure: locked presence, hazard ratio, subcategory count and
  estimated vehicle pressure; size cells micro/small/medium-small and the
  combined medium/medium-large cell.

Candidate values and deltas are forbidden selector inputs. If any required v1
base row is incomplete, `stratified_n8=UNIDENTIFIABLE`; no replacement case is
chosen.

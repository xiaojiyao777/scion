# Scion v0.4 W3 H11 C2e future-absence parent partition correction

状态：候选设计；固定哈希双审通过前不得以 production branch 或测试 fixture 覆盖
atomic base §4.4.2 的冲突行

## 1. 复现的权威冲突

本 correction只修 future-output absence 的 retained-parent topology，不修改H11输出
角色闭集、present/future协议、23-slot layout、publication/commit、indirect authority、
constructor store、fault因式分解或wire schema。

现有权威不能同时满足：

- atomic ownership base §4.4.2把 future absence写死为 slot `11`两个角色
  `closer-properties/exec-stop-post-properties`、slot `10`其余八个角色；
- accepted harness manifest contract只要求每个output是 exact `input_root`或
  `receipt_root` immediate child；没有按role冻结parent；
- accepted `_root_c1a_authority_model`把除present `run-main-properties`外的output放入
  receipt root，因此它的十个future outputs是 `n_input=0, n_receipt=10`；
- 旧accepted retained implementation按每个manifest path的exact parent选择两个已
  retained directory之一；
- C2e implementation oracle声称继承base exact borrow/consumer table，不能由candidate
  或单一fixture自行覆盖。

因此 `2/8`和当前fixture的`0/10`都不是业务authority。正确闭包是：十个future role
逐项由sealed manifest path决定属于两个exact retained parent之一；C2b一次验证并冻结
partition，C2c只消费两个typed tuple，通过两个固定 literal-slot loop执行。production
不得逐item选择parent slot。

## 3. 扩展既有 frozen partition，不新增 helper class

为避免新的aggregate/helper层，扩展既有generated frozen value：

```python
@dataclass(frozen=True, slots=True)
class H11RootClosedPartition:
    present_prerequisites: tuple[H11RootRolePath, ...]
    future_absence_inventory: tuple[H11RootRolePath, ...]
    frozen_root: H11RootRolePath
    input_future_absence: tuple[H11RootRolePath, ...]
    receipt_future_absence: tuple[H11RootRolePath, ...]
```

field order exact如上；无method/property/custom constructor。existing
`H11RootClosedPartition.__init__` generated leaf保持同一qname，参数增加三项并全部由
`_consume_ready_commit`唯一caller以keyword传入。

`future_absence_inventory`仍是wire/protocol的canonical 11项（十output加frozen-root）；
其他三field只属于internal frozen projection，不进入manifest、READY、barrier JSON或
receipt projection：

```text
frozen_root is the exact future_absence_inventory member for role frozen-root
output_inventory
  == tuple(item for item in future_absence_inventory if item.role != "frozen-root")
input_future_absence
  == the identity-preserving canonical-order projection of output_inventory whose
     sealed path parent is the retained input-root
receipt_future_absence
  == the identity-preserving canonical-order projection of output_inventory whose
     sealed path parent is the retained receipt-root
the two tuples are disjoint by object identity, role and path, and their exact union
  is output_inventory; the retained input/receipt parent directory identities are distinct
every member is the same H11RootRolePath object as its output_inventory member
len(input_future_absence) + len(receipt_future_absence) == 10
```

两tuple均允许empty；这不是预算、采样或optional coverage。

## 4. C2b唯一 partition owner

`_consume_ready_commit`在构造`H11RootClosedPartition`前必须：

1. 证明manifest output role/path闭集与READY present/future inventory cross-binding；
2. 证明两个present source仍固定 `h0 -> slot4<-10`、
   `run-main-properties -> slot3<-11`；本 correction不改变present topology；
3. 取future output的canonical `H11RootRolePath` objects；
4. 以path parent与已经retained的
   `authority.input_root_directory.reference.path`、
   `authority.receipt_root_directory.reference.path`精确比较，分别append到两个local
   literal list；third parent立即fail；
5. 一次转换为两个tuple并构造上述partition；之后不得保留mutable list、mapping、
   parent-slot value或role→parent registry；
6. `_publish_permit`与后续phase只能从exact Ready predecessor读取partition，禁止重新
   读取manifest并重新分组。

C2b grouping是pure path/value validation，不borrow、不stat、不产生runtime boundary。
它没有固定 `n_input/n_receipt`，但两者由sealed fixture逐项确定且和exact为10。

## 5. C2c fixed two-loop topology

atomic base §4.4.2的两条future row被本节替换为：

| caller | literal slot | exact syscall | static/runtime count | state |
| --- | ---: | --- | --- | --- |
| `_publish_permit` | `15` | `os.stat("frozen", dir_fd=self._slots[15].borrow(), follow_symlinks=False)` | `1/1` | `READY_CONSUMED` |
| `_publish_permit` | `11` | input tuple的一个fixed loop body：`os.stat(item.path.name, dir_fd=self._slots[11].borrow(), follow_symlinks=False)` | `1/n_input` | `READY_CONSUMED` |
| `_publish_permit` | `10` | receipt tuple的一个fixed loop body：`os.stat(item.path.name, dir_fd=self._slots[10].borrow(), follow_symlinks=False)` | `1/n_receipt` | `READY_CONSUMED` |

`n_input/n_receipt >= 0`且和exact `10`。两个loop按partition tuple canonical order，input
先于receipt；frozen-root先于两个loop。每项必须missing且非symlink语义沿用base。

禁止：

- `parent_slot` local、conditional slot expression、role branch、mapping/resolver；
- 在一个loop中根据item选择slot；
- 对empty tuple伪造一次stat或跳过另一个非empty partition；
- 重新从manifest path选择parent、`Path.exists`或absolute-path stat fallback；
- 合并为通用`stat_absence(slot, items)` helper。

这保留两个static literal borrow sites，同时允许业务合同的全部sealed two-parent分布。


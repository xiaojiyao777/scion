# P4：跨 attempt 材料、源码保留与 fresh import

*2026-11-15 · 编码前实施合同；实施状态和结果只在 TASK/current-state*

依赖 [P3](v0.5-p3-session-permissions-and-handoff.md)，细化
[机制设计 §4](v0.5-continuous-algorithm-research-design.md)。V3 §4/5/8/11–16
约束信息流；本模块完成 M 的工程能力，不证明研究效果或 CVRP 独立收益。

## 1. 配置、接口和负责组件

`research_materials_enabled`（M）控制后续 H 暴露与长期 source 保留；
`public_observation_enabled`（O）控制 observe。二者独立：O-only 保持 P3，
M-only 可写/读/搜材料但不能执行 observe，二者关闭保持旧请求。
任一开启都需显式 CodeResearchLimits 和完整 ObservationBudget；M-only 复用
problem-owned 公开声明以校验源码投影，不启动 runner/checker。

CampaignManager 新增 `research_material_imports: Sequence[str]`，CLI 可重复
`--research-materials DIR`，按参数顺序导入明确目录的 `index.json` 及其列出的文件。
未开启 M 却传导入路径是配置错误，不能忽略。源码 `--source-tree`、既有
H-only `--research-history` 和材料导入三个输入独立；不扫描旧 campaign。

`ResearchContinuity` 负责关闭会话材料索引、公开导出/导入、长期源码副本。
PublicResearchController 负责会话可见集合和错误传播；WorkspaceService 仅调用
可选保留回调，不理解笔记、问题或算法语义。没有新调度器、状态恢复或 authority。

## 2. 可见权限与修订

|阶段|允许|不允许|
|---|---|---|
|H，M 开|本 campaign 已关闭 H/C 的全部公开材料、显式导入材料、允许的历史源码投影、当前 H/公开 fixture|私有保存树、正式数据目录、其他仍开放会话、任意宿主路径|
|H，M 关|P3 当前 H/fixture 集合|新增跨 attempt 材料|
|C|当前 approved H 冻结选集、当前 C/fixture|通用历史、旧 C、H 读过但未生成的历史文件|
|Protocol/Decision|原有正式输入|所有研究材料|

当前 H 可以据历史写新解释/修订；supersedes 指向可见旧文件，不删除或覆盖原件。
不能直接把历史 ref 交接给 C；handoff 仍只选本 H 生成文件。H 读取历史不构成
必须引用/使用的门槛。索引完整，不 top-k，不以摘要替代原件。

会话关闭后发布其已完成文件；包括 abstain、abandon、Contract reject 和观察失败
留下的负面/部分输出。关闭只发生一次，不恢复 provider 会话。下一 H 获取 detached
索引，旧投影不变。branch/session/source 条件为普通定位信息，不控制调度或源码。

## 3. 普通材料格式与 fresh import

`public_research/continuity/index.json` 为受控公开导出入口：
`{schema_version: 1, entries: [...]}`；只含文件元数据和相对引用，不包含正文。
文件在同目录 `files/` 下。entry 保留 ref/kind/bytes/phase/source_condition，
可选 origin_ref/origin_scope/reference_origins/branch/session/supersedes_ref/dependencies/
missing_dependencies/availability/source_path/source_availability。
类型为 note/script/input/output/request/observation/source；availability 明确 available
或 unavailable。source_condition 仅含角色、普通 source_ref、可选 draft_revision；
不携带绝对主机路径。source_availability 区分 retained（本 campaign 完整树仍在）、
projection_only（只导入公开投影）和 unavailable；不把历史来源声明当成本 campaign 验证。
已完成 observation 的输入、脚本、实际公开源码有可解析引用。

公开导出从允许集合生成，不复制内部 record、正式 metrics、trace、控制状态或完整
私有树。正文精确复制，JSON 中原有引用不重写；origin_ref/origin_scope、逐层保留的 reference_origins 和 dependencies
提供无损定位。输入和脚本不因导入而成为可信事实，source 文件不能成为 executable base。

导入严格校验版本、字段、类型、规范相对路径、重复 ref、数量/字节与公开元数据。
每个导入目录有按参数顺序生成的本地命名空间，同名文件不覆盖；不按内容去重。
只复制列出文件，逐组件拒绝 symlink、hardlink、特殊文件、穿越和当前正式文件别名。
缺文件/缺依赖保留索引并标明 unavailable，读取返回 MATERIAL_UNAVAILABLE；
结构错误拒绝整个导入，不静默删项。未导入的依赖不从旧 campaign 或当前 source 补齐。
导入使用源 campaign 的 `public_research/continuity`，不使用整个 campaign 根。
历史完整树缺失时笔记仍可读并标 unavailable；若缺的是本次所需保存的 current/base，
则首次 dispatch 前返回 SOURCE_UNAVAILABLE，不能用现有 champion 补缺。
索引内的外部作者声明均不认证；人工改名复制的私有知识不能由格式校验自动识别。

导入在首次 provider dispatch 前独立复制，源目录随后变化不影响新 campaign。
不导入 budget、队列、champion/version、branch state、ready 或 provider session。
新 campaign 的计数从零开始，导入复制本身计入新预算。已终止 campaign 永不 resume。

## 4. 源码保留与清理顺序

完整算法树与公开投影分开。M 开启时保存初始完整 baseline、H 选定的完整 base，
并在 WorkspaceService 接受新 candidate、删除旧 head 或弃置 branch tree 前保留
实际树。副本放在 `retained_sources/序号/tree`，只供 operator 使用；同一已冻结
路径可复用普通副本，不引入 hash identity，不从 patch 重建。

完整保存复制所有普通文件和空目录（生成的 __pycache__ 排除），不把它当公开闭包。
只有 problem 声明的 subject workspace 路径通过正式文件排除后形成 H 的 source
索引。M 不能让历史树成为 subject role；observe 仍只用 current/base/draft。
观察实际 draft 的公开执行副本另由 P2 保存，失败 draft 仅为材料，不成为保留的
verified head。source 条件不因 champion 改变、sibling 阅读或 stale reconcile 改写。

顺序：保存完整树到临时目录 → 生成允许投影 → 发布普通索引 → 才允许旧路径 cleanup。
accept_candidate 已完成绑定后保留失败，不撤销绑定/Decision；跳过旧树删除，记录
材料故障并阻止下一次研究 dispatch。abandon 清理失败同样不复活分支。没有重新审批
已完成 Decision。永久 champion snapshots 继续由原有流程保留。

## 5. 资源与失败路由

复制、索引、投影的 CPU/wall 和存储计入现有共享预算。单次完整树使用
max_source_bytes/max_files_per_action，导入索引使用 max_source_bytes 和
max_collection_items；所有实际文件累计受 max_storage_bytes 限制。不能删除旧负面
材料或截断索引来腾空间。源文件检查与复制用现有无链接有界 copier。

|失败|路由|
|---|---|
|未开 M 导入、非法格式/重复/越界元数据|setup NOT_EVALUATED，首次 dispatch 前拒绝|
|导入的非 UTF-8 脚本被请求执行|INPUT_INVALID 动作反馈；保留原字节，不启动进程，可继续修订|
|历史文件/依赖缺失|保留 unavailable；开放会话枚举反馈，无当前 source 替代|
|复制违反公开闭包/别名隔离|BLOCKED_INFRA；不暴露部分导入|
|共同存储/时间耗尽|RESOURCE_EXHAUSTED；fresh H 不重置共同额度|
|磁盘/索引持久化失败|BLOCKED_INFRA；未完成发布不返回可用引用|
|中断/未知内部错误|INTERRUPTED / NOT_EVALUATED，不丢既有完成文件|
|会话关闭时发布失败|不掩盖已发生的主失败；成功提案返回前检查故障，下一 dispatch 必须停止|
|正式 Decision 后保留失败|保留 Decision/已绑定 head，跳过原树删除，记材料故障；下一研究停止|
